# Project Management (PM) - TuranX64

## Vision
The goal of TuranX64 is to create the most stable, performant, and user-friendly mobile client for SAMP. We focus on bridging the gap between PC and mobile gameplay by providing intuitive controls and superior optimization.

## Current Project State
The project is currently in an active development phase, transitioning from a core feature-set to refinement and optimization.

### Milestones Reached:
1.  **Stable x64 Foundation**: Core engine hooks and network layers are operational on 64-bit architectures.
2.  **Custom Control System**: Users can now self-configure their HUD with the new Dynamic Button System.
3.  **Hybrid UI Integration**: Successful integration between Android's native view system and the C++ rendering engine.

## Development Principles
*   **Performance First**: Every change must be evaluated for its impact on FPS and battery life.
*   **User Customization**: Empower the player to decide how their game looks and feels.
*   **Stability**: Maintain high compatibility across various Android devices and server scripts.

## Roadmap
*   **Short-term**: Finalize non-destructive client optimizations (Streaming & CPU).
*   **Medium-term**: Improve vehicle handling and physics synchronization.
*   **Long-term**: Implement a full visual HUD editor and advanced modding support.
